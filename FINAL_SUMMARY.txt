🚀 QUICK SETUP (5 MINUTES):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Build the server:
   cd d:\Agentic-AI-Test\gitHubMcpServer
   npm run build

2. Open VS Code settings (Ctrl+Shift+P → "Preferences: Open User Settings (JSON)")

3. Add this configuration:
   {
     "mcpServers": {
       "github-patterns": {
         "command": "node",
         "args": ["d:/Agentic-AI-Test/gitHubMcpServer/dist/index.js"],
         "env": {
           "GITHUB_TOKEN": "ghp_your_token_here"
         }
       }
     }
   }

4. Restart VS Code

5. Verify: Look for ✓ github-patterns in MCP panel

6. Test: Ask Claude "Search for error handling patterns"
